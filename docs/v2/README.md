# Protocol V2 documentation tree

Protocol V2 is the project’s locked causal branch within **Research Stage 1**.
It was designed to answer one
question before moving toward anything strategic:

> Can a carefully chosen internal edit reliably make the model answer with a new, unseen target while the edit remains small and selective?

The answer was **not yet**. The original H0 topology failed, and the recovery
test moved answer scores but did not convert often enough to target top-1.

## Locked claims

- H0 was confirmatory and failed.
- H0R-B was exploratory and used only already-burned country controls.
- H0R-C was prospective and failed its target-answer conversion threshold.
- H0R-D and the original latent-truth/strategic-reporting branch were not opened
  because H0R-C failed.
- V2-SR-1, V2-SWA-1, and V2-ST-1 were later controlled observational follow-ons.
  They do not repair the H0/H0R causal verdict and do not establish strategic
  intent or a validated J-space mechanism.
