# Protocol V2 hypotheses and claim gates

- **H0:** the local pipeline reproduces numerical semantics and a causal
  flexible-generalization effect, with band/all-position clamping stronger than
  one-layer/final-position clamping.
- **H1:** explicit latent truth remains readable during matched misreporting.
- **H2:** the same dissociation survives when truth is computed rather than
  copied from the prompt.
- **H3:** latent truth remains readable when used for action without verbal
  report.
- **H4:** latent-state swaps feed the downstream reporting computation and
  produce the predicted policy-dependent literal sign reversal.
- **H5:** world state and recipient/incentive state are separable.
- **H6:** latent-state evidence emerges before selected-report evidence.
- **H7:** a frozen latent-state monitor transfers to an unseen task family.
- **H8:** persistent workspace interventions outperform local interventions
  when downstream layers reconstruct the original state.

Only H0 is confirmatory in the first V2 run. H1–H8 remain gated and unopened.
