# Protocol V2 research specification — Stage 1 causal instrument

V2 asks whether J-space exposes a task-relevant latent state `X` when a model's
selected report `R` differs from it under policy context `U`. The target is a
causal decomposition `R = f(X, U)`, not a vocabulary detector for words such as
*lie* or *deception*.

The execution order is gated:

1. validate numerical and hook parity, direction construction, analytic swaps,
   task-independent workspace localization, and Anthropic-style flexible
   generalization;
2. observe explicit true-state/report-state trajectories;
3. remove prompt copying with computed truth;
4. swap the latent state under matched truthful and misreport policies;
5. only then add recipient context, endogenous strategy, and cross-task monitors.

No strategic-task result is interpreted unless H0 passes. Every rendered
example stays grouped with all factorial variants, and discovery, validation,
and locked test splits occur at the scenario-template-family level. Raw outputs
are immutable; derived tables and figures must be reproducible from them.

The strongest planned causal estimand is the world-state-by-policy interaction:
the same `A→B` latent swap should move a truthful report `A→B` but a report-other
policy `B→A`. Direct-answer steering, identity swaps, unrelated directions,
fixed-seed random directions, out-of-band layers, lexical controls, and output
symbol transfer are required before a mechanistic claim.

V2 does not claim consciousness, universal lie detection, deceptive intent in
deployed systems, or monitor robustness to adversarial evasion.
