# Protocol V3 — J-space intervention replication

## What V3 was trying to do

V3-JI1 asked whether the J-space intervention could be characterized more
cleanly on a fresh, behaviorally competent corpus. It kept the old V2 failure
intact and separated four questions: is the edit numerically valid, does it move
the intended semantic answer, is the change low-distortion on average, and does
it reliably make the requested answer top-1?

## Where it stopped

The burned engineering phase passed its numerical and directional proceed gate.
The fresh candidate-selection phase did not find enough clean, tokenizer-valid
blocks. The study stopped before Phase D, so no fresh intervention result exists.
The burned effect is useful implementation evidence, not prospective
confirmation.
