# Protocol V4 — strategic epistemic search

## What V4 was trying to do

V4 asked a simple behavioral question: if the model has just made a correct
decision and we keep its rationale, does that rationale make a later report
about the decision’s likely consequence worse?

## What happened

Yes. The effect appeared in discovery, survived held-out confirmation, and
survived a fresh counterbalanced 360-decision study. The result supports broad
relational interference. It does not establish the originally suspected
label-binding or position-binding mechanism, and no J-space intervention was run.

The current best next step is a cheap fresh check of the strategic-frame
interaction. A mechanistic sweep is not licensed by the current evidence.
