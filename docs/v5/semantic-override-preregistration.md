RBG-1 failed because Qwen often selected the claim whose semantic content matched
the desired receiver conclusion while ignoring a demonstrated contrarian response
policy. RBG-2 asks whether this is merely policy-inference failure or a sharper
knowledge/action dissociation.

## Factorial intervention

Sixteen fresh base games cross human receiver/device framing, aligned/opposed
incentives, literal/contrarian response policies, inferred/explicit policy access,
and meaningful claims/opaque signal tokens. There are two counterbalanced options
and no message costs or silence choice.

In the explicit condition, the prompt states the complete option-to-response map.
In the opaque condition, the same map is attached to semantically meaningless
tokens. Every context receives one action query and two independent consequence
reports, one for each option.

## Confirmatory gates

The explicit opaque-token population must first exceed 90% action accuracy, 80%
in every frame × incentive × type cell, and 90% option-consequence report accuracy.
Otherwise the task is not a valid control.

The semantic-override hypothesis is promoted only in explicit contrarian games if:

- opaque-token action accuracy is at least 85%;
- meaningful-claim action accuracy is at most 65%;
- consequence-report accuracy for meaningful claims is at least 85%;
- the opaque-minus-claim action gap is at least 20 percentage points; and
- the two-sided exact base-game cluster sign-flip p is below .05.

The strongest diagnostic subset contains trials where both option consequences are
reported correctly but the action is wrong, specifically because the chosen claim's
content equals the target while its explicitly stated receiver consequence does not.

No mechanistic claim is licensed by this screen. A positive result permits a fresh
natural activation-interchange study separating option consequence, claim meaning,
and selected action.
