# V4-SES-1 — strategic epistemic search

## The question

After the model makes a correct decision, does keeping its explanation nearby
make it harder to answer a simple question about what that decision will cause?

This is a behavioral test. It does not edit J-Space or claim that the model has
beliefs about another agent.

## What happened

The model solved the games well. When we kept the model’s correct rationale,
its later report of the selected action’s likely response became worse than
when we kept only the final action. The effect survived a held-out confirmation
and a fresh counterbalanced study with 360 decisions.

The most useful interpretation is broad interference: extra relational text can
push the model away from the true response. The original suspected label- or
position-binding mechanism was not established. A larger effect in sender/
receiver wording than in an isomorphic device frame is an interesting
exploratory lead, not a confirmed mechanism.
