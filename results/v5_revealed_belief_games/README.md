# V5-RBG-1 — receiver-policy competence gate

## The question

Can the model use a demonstrated receiver policy in a small strategic game?
For example, if the receiver always reverses the sender’s claim, can the sender
choose the claim that produces the desired receiver response?

This was a gate, not a mechanism experiment. The model had to understand the
game before we could interpret later action/report comparisons.

## What happened

The gate failed. Baseline action accuracy was 52.08%, the weakest frozen cell
was 0%, and only 11.46% of matched receiver-type pairs had both correct,
different actions. The model often followed the literal meaning of a claim
instead of the demonstrated contrarian mapping.

Because competence was insufficient, no internal-state analysis was opened and
RBG-1 makes no claim about deception, inferred beliefs, or action/report
contradiction. Its value was diagnostic: it showed that literal message meaning
had to be separated from receiver-policy use in the next study.
