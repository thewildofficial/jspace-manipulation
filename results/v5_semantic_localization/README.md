# V5-RBG-3 — semantic localization

## The question

Does the large RBG-2 action gap survive a fresh prompt family, and which part of
the wording causes the remaining errors?

## What happened

The large RBG-2 effect did not reproduce: opposed assertion accuracy was 85.42%,
above the frozen maximum error threshold. The confirmatory replication therefore
failed. Still, the seven remaining assertion errors were selective: opaque
tokens, quoted strings, and labeled buttons were all perfect; every assertion
error had correct consequence reports and was repaired by same-trajectory causal
rehearsal.

The lesson was to manipulate history and rule format inside one matched study,
rather than compare two prompt families after the fact. That is what RBG-4 did.
